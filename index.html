01 · About

Where finance meets automation

The CA syllabus is tough — but inefficient, manual workflows make it tougher. So I started building the fix.

I work across Statutory Audit, GST and Direct Tax at VCAS & Co LLP, and I kept hitting the same wall — too much manual work, too little automation. So instead of just complaining about it, I started building.

That turned into AI-powered tools using the Claude API, Excel automations for CA workflows, and a full desktop suite that firms and students actually use — not portfolio pieces, actual production software with installers, auto-updates and real users.

Alongside this, I run e-commerce brands on Meesho & Flipkart, handling GST reconciliation, order automation and finance operations end-to-end — which keeps every tool I build grounded in a real, messy, real-world problem.
